**Zero possible unsoundness and zero false positives across 124 units
spanning scalar range, overflow, index, division, length, discriminant,
initialization, loop-invariant and loop-variant obligations.** On the 34
`weak` units GNATprove's deliberate `medium`/`high` check was never once
answered `proved-safe` by AdaLang — every one landed in bucket 5 (16) or as
an AdaLang-conservative/only obligation.

### Reading the numbers

- **Matched-pair yield is low by design.** Many units leave AdaLang's
  bounded verifier entirely at `Unproved`/`Unsupported` (contracts,
  quantifiers, relaxed initialization), so "both safe" is only 44 of 428
  matched pairs. The signal this corpus carries is the two **zero**s in
  buckets 3 and 4 across a very wide construct spread, not the matched
  count — the same framing `benchmarks/coap_spark/` uses.
- **Count-mismatch (168) is proportionally higher here** than on the
  single-project corpora: GNATprove splits a check into several VCs at
  distinct columns of one source line, AdaLang records one obligation per
  `(line, kind)`, so `compare.awk` reports the location for manual review
  rather than guessing a pairing. None of the 168 is a safety
  disagreement (independently re-scanned).

## Two analyzer mistakes found and fixed

This first run surfaced two defects; both are fixed with regression tests
and re-confirmed by this run (which is post-fix).

| ID | Unit that found it | Mistake |
| --- | --- | --- |
| `FP-064` | `OB26-006__ctex_array_ret_func` | Indexing into an array *slice* (`Items (1 .. Last) (1)`) was proved safe against the array *type*'s index subtype, ignoring that the slice's own bounds `1 .. Last` are empty when `Last = 0` — a possible unsoundness. Fixed by recording a sliced-prefix index check conservatively as `unproved`. |
| `FP-065` | `W316-007__string_multidim` | `pragma Assert (False)` reported as a definite error on a line the enclosing `if` guard makes unreachable (the `if` line itself always raises `Constraint_Error`). Fixed by keeping the definite-error verdict only where every enclosing branch guard is provably taken. |

`W316-007__string_multidim` is **excluded from `MANIFEST.tsv`**
(`pick_manifest.py`'s `HAND_EXCLUDE`) for a reason independent of the
FP-065 fix: GNATprove's own baseline proves the line-13 aggregate range
checks that GNAT rejects at run time, so it is not a sound oracle unit.

See `quality/external_corpus_findings.md` (SPARK testsuite section) and
`quality/known_analysis_issues.tsv` (`FP-064`, `FP-065`).

## Bottom line

A construct-diversity corpus, not another large matched-pair count: 124
independently-authored SPARK regression units, none written with AdaLang's
blind spots in mind, and after the two fixes above AdaLang never calls safe
a check GNATprove cannot prove nor a definite error a check GNATprove
proves.
