## What changed since 1.17.5

Every obligation has the verdict it had with 1.17.5.

5 `Missing_Global_Contract` findings are new in `--spark` and `--verify`: a
call to a subprogram whose Global aspect names a state abstraction touches
that state (`Ada.Text_IO`'s `File_System`, `Interfaces.C.Strings`'
`C_Memory`), so a subprogram that reaches state only through such calls has
global state for which GNATprove would generate a Global (FP-181).

18 `Wrong_Parameter_Mode` findings are gone from `--recommended`: an `in out`
parameter written only on some paths is not advised mode `out`, which would
lose the caller's value (FP-187).

7 `Global_Contract_Mismatch` findings are gone from `--spark` and `--verify`:
a read or write of a constituent of a state abstraction is allowed as the
Global aspect allows the state, a body is held to its `Refined_Global`, a
constant whose value depends on no variable is no global, and an `Output`
global may be read once the body has given it a value first (FP-181, FP-189).

## Bottom line

Zero possible unsoundness and zero false positives against GNATprove on 57
matched pairs.
