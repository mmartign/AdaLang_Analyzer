## What changed since 1.17.5

Every obligation has the verdict it had with 1.17.5.

6 `Missing_Global_Contract` findings are new in `--spark` and `--verify`: a
call to a subprogram whose Global aspect names a state abstraction touches
that state (`Ada.Text_IO`'s `File_System`, `Interfaces.C.Strings`'
`C_Memory`), so a subprogram that reaches state only through such calls has
global state for which GNATprove would generate a Global (FP-181).

2 `Wrong_Parameter_Mode` findings are gone from `--recommended`: an `in out`
parameter written only on some paths is not advised mode `out`, which would
lose the caller's value (FP-187).

287 `Missing_Global_Contract` findings are gone from `--spark` and `--verify`:
a subprogram that reads only constants whose value depends on no variable
accesses no global state (FP-181).

1 `Dead_Store` finding is gone from every lane: the value a call stores at the
end of a loop pass that the next pass reads is not dead (FP-186).

## Bottom line

No analyzer failures. No GNATprove oracle for this corpus (flow-analysis
