# CubedOS comparison results — 2026-11-12

Analyzer run of 2026-11-12 with release 1.15.0, replacing the 2026-11-11 run
of release 1.14.0. GNATprove was not re-run: the corpus is pinned, and its
output of 2026-10-02 was compared again as saved. Earlier runs are in the
Git history of this directory, and what each release changed is in
`CHANGELOG.md`.

## Environment and scope

- cubesatlab/cubedos: `c402301000a5a92237e0f7ab106186a48273cf24`
- AdaLang Analyzer: release 1.15.0
- GNATprove `--mode=prove`, run 2026-10-02 (FSF 16.1.0, Why3 1.8.2+git, Z3
  4.15.4, CVC5 1.3.2, Alt-Ergo 2.6.1), AUnit resolution via a throwaway
  local crate.

This corpus is not fully proved: of GNATprove's 64 messages, 18 are `high`
and 21 `medium`. It is a weaker oracle than the five fully proved corpora
and is not counted with them.

A pair is a `(file, line, kind)` at which each tool has exactly one
obligation. Of the ten pairs six are range checks and four are preconditions,
all of them left at `medium` by GNATprove and `Unproved` by AdaLang. Five more
locations are not paired because AdaLang has two obligations of a kind on a
line where GNATprove has one message.

## What changed since 1.14.0

3 range checks are added (2 `Proved_Safe` and 1 `Unproved`), which 1.15.0
raises on the value a function returns and on the bounds of the range
constraint of a `for` loop or a quantified expression.

No obligation is gone.

Every obligation has the verdict it had with 1.14.0.

## Bottom line

Zero possible unsoundness, zero false positives, and no file-level
failures.
