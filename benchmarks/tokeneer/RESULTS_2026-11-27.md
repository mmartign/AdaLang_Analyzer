## What changed since 1.17.5

3 `Global` aspects that were `Unproved` are proved: each body reads an
`Output` global only after giving it a value, which the analyzer now sees
through a callee's `Refined_Global`, a record written a component at a time
and a plain loop (FP-189).

No obligation that 1.17.5 proved is lost.

2 `Missing_Global_Contract` findings are gone from `--verify`: a subprogram
that reads only constants whose value depends on no variable accesses no
global state (FP-181).

323 `Global_Contract_Mismatch` findings are gone from `--verify`: a read or
write of a constituent of a state abstraction is allowed as the Global aspect
allows the state, a body is held to its `Refined_Global`, a constant whose
value depends on no variable is no global, and an `Output` global may be read
once the body has given it a value first (FP-181, FP-189).

1 `Dead_Store` finding is gone from `--verify`: the value a call stores at the
end of a loop pass that the next pass reads is not dead (FP-186).

## Bottom line

Zero possible unsoundness and zero false positives on 451 matched pairs.
