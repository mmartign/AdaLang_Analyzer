# Tokeneer comparison results — 2026-08-13

First run of this benchmark directory (`benchmarks/tokeneer/`), which
brings Tokeneer into the same `run.sh`/`compare.awk`/`RESULTS_*.md`
convention the other fully-proved corpora use. See `README.md` for why
Tokeneer's own longer history lives separately in
`quality/external_corpus_findings.md` instead.

## Environment and scope

- AdaCore/spark2014: `a97467e91a16409c866434fcc7a5f553bbd98b8a`,
  `testsuite/gnatprove/tests/tokeneer`, 120 source files
- AdaLang Analyzer: `1.0.0-rc1`, commit `aeb345b939e2a341f3abf7ec1873f1c46d27de4d`
  (includes the enum-sort `VC_Prover` support from the same session)
- GNATprove: FSF 16.1.0, Why3 1.8.2+git, CVC5 (via `--prover` default),
  Z3, Alt-Ergo 2.6.1
- Invocation: AdaLang `-P test.gpr --verify --format=json`; GNATprove
  `-P test.gpr --mode=prove --output=oneline --report=statistics`, i.e.
  `test.gpr`'s own `Prove` package switches (`--function-sandboxing=off`,
  `--proof-warnings=on`, `--level=2`) plus `--report=statistics` added on
  the command line (see `README.md` for why)

## Primary results

| Lane | Time | Result |
| --- | ---: | --- |
| AdaLang `--verify` | 10.2 s | 120 files; 6,697 proof obligations; 1,741 `Proved_Safe`, 0 `Definite_Error`, 4,624 `Unproved`, 332 `Unsupported` |
| GNATprove `--mode=prove --level=2 --report=statistics` | 279.2 s | 2,286 check messages, all `info` (proved); 0 `medium`/`high` (not proved) |

GNATprove's own summary (`gnatprove.out`) confirms zero unproved checks:
2,219 total (Flow 1,366, Provers 831, Justified 22, **Unproved 0**) —
Tokeneer is, as AdaCore describes it, fully proved on this pinned revision
and toolchain, making it a trustworthy oracle the same way SPARKNaCl,
Saatana, libkeccak, and coap_spark are.

## Agreement: matched obligations

**221** obligations matched 1:1 (file, line, kind):

| Bucket | Count |
| --- | ---: |
| Both safe (AdaLang proved-safe, GNATprove proved) | 15 |
| AdaLang conservative (unproved/unsupported, GNATprove proved) | 206 |
| **Possible AdaLang unsoundness** (proved-safe, GNATprove NOT proved) | **0** |
| **AdaLang false positive** (definite-error, GNATprove proved) | **0** |
| Both flag a problem | 0 |

**Zero possible unsoundness and zero false positives** — Tokeneer joins
SPARKNaCl (890 matched pairs), Saatana (101), libkeccak (212), and
coap_spark (853) with the same result: across five independently-authored,
fully-proved SPARK corpora and 2,277 combined matched-pair obligations,
AdaLang has never called something safe that GNATprove could not prove,
and never called something a definite error that GNATprove proved safe.

Tokeneer's own "both safe" share (15/221 ≈ 7%) sits between SPARKNaCl's
(~4%) and libkeccak's (~24%), consistent with `benchmarks/README.md`'s
observation that this varies a lot by code style rather than converging on
one number.

Count-mismatch keys (not auto-paired — same source line legitimately
carries more than one obligation of that kind on one side, most often two
`precondition` checks where AdaLang counts separately what GNATprove's
`--output=oneline` reports as one message): 170. Every one is a coverage
question, not a disagreement between the two tools on any single obligation
both evaluated.

## Coverage-only counts (not agreement failures)

- **AdaLang-only** (no GNATprove `--mode=prove` counterpart for that kind):
  5,439 — dominated by `initialization-check` (3,282, a flow-analysis
  result GNATprove reports through its own separate `Initialization`
  category, not `--mode=prove`) and `range-check` (1,611).
- **GNATprove-only** (mapped kind, no AdaLang obligation at that location):
  207, spread across `precondition` (47), `range-check` (96), and smaller
  counts of `postcondition`/`index-check`/`integer-overflow`/etc. — cases
  where GNATprove's flow-sensitive whole-program view derives a check
  AdaLang's intraprocedural CFG interpretation does not register at all,
  consistent with the documented scope difference (`POSITIONING.md`).
- **GNATprove messages with no AdaLang kind mapping**: 1,574 — almost
  entirely `initialization of "X" proved` (per-object flow-initialization
  facts, a different granularity than AdaLang's own
  `initialization-check`), `implicit aspect Always_Terminates ... proved`,
  `data dependencies proved`, and `flow dependencies proved` — categories
  AdaLang's bounded scalar verifier does not attempt to model at all (see
  "Out of scope" in `POSITIONING.md`).

## Bottom line

Tokeneer's first run in this benchmark directory reproduces the same
zero-unsoundness, zero-false-positive result every other fully-proved
corpus here has shown, on the project's oldest and largest (by proof
obligation count) external corpus yet in this directory. As with every
other benchmark, the much larger AdaLang-only and GNATprove-only pools
reflect a real scope difference, not a scoring gap — see `POSITIONING.md`
for what `--verify` does and does not attempt relative to GNATprove.
