## What changed since 1.17.3

Every obligation has the verdict it had with 1.17.3.

2 `Uninitialized_Read` findings are gone from `--automotive` and
`--recommended`: an object whose access value a call in the value of an
assignment is given (`X'Access`, `X'Unchecked_Access`) is no longer taken as
read there: the call may store into it (FP-172).

3 `Overwritten_Assignment` findings are gone from every lane: a value assigned
to an object of a package that a call between the two assignments can read --
a flag set around a callback, saved and restored around calls that read it --
is no longer reported (FP-175).

## Bottom line

No file-level failures, and no `Definite_Error`. No GNATprove oracle for
this corpus (legality-error boundary, unchanged), so nothing here says
whether a verdict is right.
