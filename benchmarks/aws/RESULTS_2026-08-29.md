`--automotive` lane — this is exactly the `--verify` lane's own ordinary

enables its own independent, much broader rule set (`Rules.Automotive_Rules`
in `src/adalang_analyzer-rules.ads`/`-cli.adb`, 46 distinct rule kinds

(2,089), `Missing_Depends_Contract` (836), `Missing_Global_Contract` (827),
and `Magic_Number` (822) — ordinary breadth checks, not a
concurrency-prohibition spike. This run's own concurrency-prohibition
numbers (`No_Select`/`No_Requeue`/`No_Rendezvous`/etc.) were not
re-extracted individually this pass; see the corpus's own analysis history
for that breakdown if needed. Treated here as a prior-document transcription
error found and corrected during this refresh, not an analyzer behavior
change — nothing in the commits since the prior run touches `--automotive`'s
rule selection.
