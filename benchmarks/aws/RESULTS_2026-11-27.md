## What changed since 1.17.5

Every obligation has the verdict it had with 1.17.5.

25 `Missing_Global_Contract` findings are new in `--automotive`, `--spark` and
`--verify`: a call to a subprogram whose Global aspect names a state
abstraction touches that state (`Ada.Text_IO`'s `File_System`,
`Interfaces.C.Strings`' `C_Memory`), so a subprogram that reaches state only
through such calls has global state for which GNATprove would generate a
Global (FP-181).

3 `Wrong_Parameter_Mode` findings are gone from `--recommended`: an `in out`
parameter written only on some paths is not advised mode `out`, which would
lose the caller's value (FP-187).

3 `Uninitialized_Output` findings are gone from every lane: a loop that goes
round at least once sets what its first pass sets, an out parameter with
relaxed initialization is not checked, and a function called in a declaration
sets the out parameter it is given (FP-183, FP-184, FP-185).

425 `Missing_Global_Contract` findings are gone from `--automotive`, `--spark`
and `--verify`: a subprogram that reads only constants whose value depends on
no variable accesses no global state (FP-181).

2 `Dead_Store` findings are gone from every lane: the value a call stores at
the end of a loop pass that the next pass reads is not dead (FP-186).

## Bottom line

No file-level failures, and no `Definite_Error`. No GNATprove oracle for
this corpus (legality-error boundary, unchanged), so nothing here says
whether a verdict is right.
