## What changed since 1.13.0

No obligation is added. 99 range checks of an array value are gone (all
`Unproved`): an array value is no longer given the range check of a scalar.

1,108 obligations that were `Unproved` moved to `Proved_Safe`: 832 index
checks, 83 overflow checks, 83 preconditions, 46 range checks, 23
postconditions, 20 assertions, 14 loop invariants preserved by an iteration
and 7 loop invariants on entry.

No other obligation that 1.13.0 proved is lost.

## Bottom line

Zero possible unsoundness and zero false positives on 3,075 matched pairs.
