and `ASR64_16` in `sparknacl.ads`. AdaLang leaves all seven `Unproved`.

## What changed since 1.12.3

No obligation is added and none is gone.

113 obligations that were `Unproved` moved to `Proved_Safe`: 36 predicate
checks, 18 range checks, 17 assertions, 16 loop invariants on entry, 15 loop
invariants preserved by an iteration, 3 index checks, 3 preconditions, 3
overflow checks and 2 postconditions.

One loop invariant 1.12.3 proved preserved by an iteration is no longer
proved: it held only because the next iteration was checked with the loop
parameter at the value it had (FP-139). None other that 1.12.3 proved is lost.

## Bottom line

Zero possible unsoundness and zero false positives on 1,114 matched pairs.
