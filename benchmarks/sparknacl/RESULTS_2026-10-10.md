## What changed since 2026-09-30

The same 9,484 obligations as before; 714 moved to `Proved_Safe` and 43
moved from `Proved_Safe` to `Unproved`.

- Newly proved: 220 overflow checks, 192 initialization checks, 178 range
  checks, 123 index checks and 1 assertion. They come from what 1.6.1 added:
  membership tests and `for` loops over an object's own range narrow
  intervals, array bounds that no declaration fixes are terms the provers
  reason about, and a call to a function in SPARK or in a `Pure` unit, or to
  a predefined attribute, no longer discards what is known, initialization
  included.
- No longer proved: 27 range checks, 14 preconditions, 1 index check and 1
  postcondition. They rested on what 1.6.1 no longer assumes: the bounds of
  an array that no declaration fixes (`FP-088`), and facts about objects
  that a call, a loop or an alias can change (`FP-090`-`FP-094`). The
  2026-09-30 comparison found none of them wrong (zero possible unsoundness
  then as now); they are withdrawn because the reasoning behind them was not
  sound in general.

18 matched pairs moved from AdaLang-conservative to both-safe. The four
"both flag" pairs are still GNATprove's own `medium` messages in
`sparknacl-sign.adb`, where AdaLang is `Unsupported`.

One `Constant_Condition` finding of the previous `--verify` run is gone: it
was reported from a loop's state before the fixed point converged
(`FP-095`).

The analyzer lane took 30 s against 87 s last run: most solver processes are
no longer started (see `CHANGELOG.md`, 1.6.2).

## Analyzer refresh 2026-10-09 (release 1.8.5)

The analyzer side was re-run on 2026-10-09 with release 1.8.5. It has the
obligations of 1.8.4, every one of them, and decides more of them. A
constant, an `in` parameter and the parameter of a loop hold a value of
their subtype wherever they are read. A call leaves an `in out` actual
initialized, and an `out` actual where the callee writes it on every path or
is SPARK code; after a call of SPARK code a scalar actual is within the
subtype of the parameter, and in SPARK code so is a scalar component of a
record. A call whose effects are not known no longer drops what is known of
the objects it cannot reach. The bounds of an array are values of its index
type, a formal has the bounds of its actual in a precondition, and an
operation of a type declared with a range is checked against the part of its
base range the language guarantees. It fixes two false-safes, `FP-117` (an
`out` actual taken to be initialized after a callee that returns without
writing it) and `FP-118` (an expression function that completes an earlier
declaration read with its formals unbound); no proof 1.8.4 had in this
corpus is lost with them. GNATprove was not re-run: its 2026-10-02 output
was compared again as saved.

## Analyzer refresh 2026-10-10 (release 1.8.6)

The analyzer side was re-run on 2026-10-10 with release 1.8.6. It has the
obligations of 1.8.5, every one of them, and decides more of them.
Conditional and case expressions are translated for the solvers. The scalar
parts of an object that its name settles have symbols of their own -- a
component of a component, a discriminant, the element of an array at an
index whose value is known -- and a record or array parameter of an inlined
expression function stands for the part of the caller's object that is its
actual. `X'Constrained` is known where the declarations say it, an access
value can be compared with `null`, and a divisor whose value excludes zero
is not zero whatever its form. It fixes one false-safe, `FP-119`: a
component read in an element of an array was one symbol for every element of
the array. GNATprove was not re-run: its 2026-10-02 output was compared
again as saved.
